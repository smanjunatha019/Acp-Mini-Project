# 2D Graphics Editor

## About
A simple console-based 2D Graphics Editor developed in C. It allows users to draw basic shapes on an ASCII canvas.

## Features
- Draw Lines
- Draw Rectangles
- Draw Circles
- Draw Triangles
- Delete Objects
- Display Canvas

## Technologies Used
- C Programming
- Structures
- Unions
- Arrays
- DDA Line Algorithm
- Midpoint Circle Algorithm

## How to Run

Compile:
```bash
gcc graphics_editor.c -o graphics_editor
